What Research Analyst does

Research Analyst is an institutional-grade equity and ETF research agent. Enter a ticker and it produces a structured, decision-intelligence report - fundamentals, technicals, macro context, competitor dynamics, and valuation - in the style of a top-tier sell-side or buy-side analyst.

Running a report

Single ticker

  1. Make sure Single Ticker is selected.
  2. Enter an equity or ETF symbol (e.g. AAPL, MSFT, SPY).
  3. Pick a Report Type (Comprehensive, Long-Term, Tactical, or All) and a Timeframe.
  4. Click Run Research. Results appear as tabs you can switch between.

Compare (2 to 5 tickers)

  1. Select Compare.
  2. Enter 2 to 5 distinct tickers separated by commas or spaces.
  3. Choose a timeframe and click Compare.

Report types

  • Comprehensive - hybrid long-term + tactical synthesis (default).
  • Long-Term - deep structural analysis.
  • Tactical / Near-Term - short-horizon, market-driven insights.

Exporting a report

Every report can be downloaded as Markdown or HTML from the report toolbar. With an API key, the same report is also available as CSV (the report's analysis tables, ready for a spreadsheet) and as a print-ready PDF, and as an embed card you can place on another page. Exports contain Research Analyst's own analysis - never raw data bundles from our sources.

Saved scenarios & sharing

With an API key you can save a report's setup (ticker, report type, timeframe, assumptions) as a scenario and re-run it any time. Every scenario has a share link: anyone with the link sees that report, in any export format, without a key. Deleting the scenario disables the link.

The Quant tab

The Quant tab runs the quantitative engine (growth trends, DuPont decomposition, forensic screens, valuation, allocation) over the same financial statements the report uses. It names that statement set at the top ("Statements: ..."), so the numbers always trace to the same source as the report.

Read the study behind those charts: Seeing Clearly — the dataviz study program behind our charts (PDF).

API access

Paid plans add a metered API: the same analysis, called programmatically with your key in the X-RA-Key header. GET /api/usage shows your plan, this month's calls, and what remains. Your key also owns a watchlist (/api/watchlist): add the tickers you follow, and GET /api/watchlist/quotes returns their current prices, each labelled with the source that served it. See the API Reference in the project documentation for endpoints and formats.

Installing on your device

  • Android APK / F-Droid: use Get the App in the top bar to download the APK (F-Droid coming soon).
  • Install as a PWA: Android Chrome → menu → "Install app"; iPhone/iPad Safari → Share → "Add to Home Screen"; macOS Safari → Share → "Add to Dock". Works offline once installed.

Data sources

Every report names its sources in its own Data Sources section, and every price carries the source that served it. Statements come from the first source where one exists:

  • SEC EDGAR (US filings, XBRL financials)
  • CVM (Brazil regulator filings), EDINET (Japan regulator filings)
  • Prices from a labelled cascade: market-direct first, then key services, Stooq, and Yahoo Finance last
  • Macro from first sources: FRED, US Treasury, Bank of Canada, ECB, Bundesbank, Eurostat, Bank of Japan, Banco Central do Brasil, and national statistics (ABS, PSA, Statistics Canada)
  • Technical indicators (computed from price data)

Troubleshooting

  • "Invalid ticker" - use letters, numbers, dot or hyphen, up to 20 characters, including the exchange suffix (e.g. RELIANCE.NS).
  • A report fails - click Retry; some thinly-covered or non-US symbols may lack full data.
  • Charts do not render - refresh the page; charts load from a CDN on first visit.
