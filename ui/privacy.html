What this service records

When you use Research Analyst, the server keeps a request log so we can operate and protect the service. Each entry holds the route requested, the method, the response status, and how long the request took. For calls made with an API key, the log holds an internal key record identifier — never the key itself. The log does not record IP addresses or query strings. Request logs are kept for 90 days and then deleted.

API keys and metering

If you hold an API key, we count the calls it serves, by endpoint and by month, so your plan allowance can be applied. You can see your own counts at any time via GET /api/usage with your key. Metering records are pruned after about 90 days.

Saved scenarios and share links

Saving a scenario stores its name and its report parameters (ticker, report type, timeframe, and any assumptions you set) under your API key. A share link displays that saved report to anyone who has the link — treat it like a password. Deleting a scenario disables its link immediately.

Payments

Paid plans are handled by Stripe. We never receive or store your card number. We store the subscription status and the API key it grants, so the service can honour your plan.

What we never do

  • No advertising, and no ad networks.
  • No third-party trackers or analytics beacons in the app.
  • No sale, rental, or sharing of personal data for marketing.
  • No harvesting of data about you beyond what is described on this page.

One disclosure: interactive charts load the Plotly charting library from its public content-delivery network in your browser, the way any web page loads a library. Everything else the app needs is served by this service itself.

Market data

Reports are generated from the public and licensed sources named in each report’s Data Sources section. We sell our own analysis. Source data we consume under licence is never sold or redistributed.
